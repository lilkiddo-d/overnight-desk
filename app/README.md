# Overnight Desk – frontend

Next.js 15 (App Router) + TypeScript + wagmi v2 / viem v2 + RainbowKit v2 + TanStack Query + Tailwind CSS v4.
Everything is read client-side from the chain (multicall batched); there is no backend.

| Route       | What it does                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------ |
| `/`         | Rate curve per collateral (last clearing rate per term), auction countdown, recent results       |
| `/trade`    | Sealed lend / borrow orders (local commitment, approve → commit), my orders: reveal/cancel/settle, secrets backup/import |
| `/auctions` | Per-book status for the current and previous epoch, permissionless "Clear auction"              |
| `/repos`    | Borrower repos (health, repay, add/withdraw collateral, auto-roll), claims, lender notes + redeem, liquidation auctions (buy/restart) |
| `/notes`    | Note marketplace: listings with implied yield, buy, list, update price, cancel                   |
| `/risk`     | Risk disclosure (a first-visit acknowledgment modal gates trading actions)                       |
| `/stake`    | Only when `NEXT_PUBLIC_PROJECT_TOKEN` is set **and** `ProjectTokenHooks.isActive()`              |
| `/blocked`  | Geoblock landing page (see `src/middleware.ts`)                                                  |

## Contract addresses

Addresses are fetched at runtime from `/deployments/<chainId>.json` (`app/public/deployments/`), written by
`contracts/script/Deploy.s.sol`. If the file for the selected chain is missing the app shows
"Overnight Desk is not deployed on this network yet". Typed ABIs live in `src/abi/` (generated by `pnpm abis`
at the repo root; do not edit).

## Run against the local fork

```bash
# 1. start an anvil fork of Robinhood Chain on :8571 with chain id 31337 and deploy (see the repo root README);
#    the deploy script writes app/public/deployments/31337.json
# 2. from the repo root
pnpm install
cp app/.env.example app/.env.local      # then set NEXT_PUBLIC_CHAIN_ID=31337
pnpm --filter app dev                   # http://localhost:3000
```

In your wallet add the network "Local fork" with RPC `http://127.0.0.1:8571` and chain id `31337` (RainbowKit
offers to add it when you click "Switch network"). Use one of anvil's well-known development accounts; never
import a key that holds real funds.

## Run against mainnet (Robinhood Chain, id 4663)

```bash
pnpm install
# app/.env.local
#   NEXT_PUBLIC_CHAIN_ID=4663
#   NEXT_PUBLIC_RPC_URL=<provider URL>  (recommended: the public RPC is rate-limited)
pnpm --filter app build && pnpm --filter app start
```

`app/public/deployments/4663.json` must exist (committed after the mainnet deployment).

## Environment variables

See `.env.example`. All are public and inlined at build time.

| Variable                         | Default | Meaning                                                                    |
| -------------------------------- | ------- | -------------------------------------------------------------------------- |
| `NEXT_PUBLIC_CHAIN_ID`           | `4663`  | Default chain. `31337` also enables the local fork in the network list.    |
| `NEXT_PUBLIC_RPC_URL`            | empty   | RPC override for the default chain.                                        |
| `NEXT_PUBLIC_WC_PROJECT_ID`      | empty   | WalletConnect project id. Empty ⇒ injected wallets only (build never fails). |
| `NEXT_PUBLIC_PROJECT_TOKEN`      | empty   | Project token address. Empty ⇒ all token/staking UI hidden.                |
| `NEXT_PUBLIC_GEOBLOCK_COUNTRIES` | empty   | Comma-separated ISO codes redirected to `/blocked` (`x-vercel-ip-country`). |

## Sealed-bid commitments

`src/lib/commitment.ts` computes
`keccak256(abi.encode(owner, bookId, epoch, side, amount, collateral, rateBps, salt))` locally, exactly like
`AuctionHouse.commitmentHash`. The contract view is never called for real orders because that would send the
sealed rate to the RPC provider. The salt is 32 bytes from `crypto.getRandomValues`. The order secret (rate + salt)
is written to `localStorage` **before** the commit transaction is sent and can be exported/imported as JSON. A lost
secret means the order cannot be revealed and forfeits the no-reveal penalty (1%).

## Deploying on Vercel

- Root directory: `app`
- Install command: `pnpm install` (pnpm workspace at the repo root; Vercel detects `pnpm-lock.yaml`)
- Build command: `pnpm build`
- Output: Next.js default
- Set the environment variables above in the Vercel project. Geoblocking relies on Vercel's
  `x-vercel-ip-country` request header; on other hosts the header is absent and nobody is blocked.
- Commit `app/public/deployments/4663.json` once the mainnet deployment exists; it is served with `no-store`.
